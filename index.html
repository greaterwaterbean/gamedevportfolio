01 About

Programmer first. Storyteller always.

I'm a Computer Science and Game Studies double major with an English minor who's happiest owning both sides of a game: the systems that run it and the story that makes them fun. On "Tails of the Tower," I was one of nine programmers in a 24-student capstone studio. I built enemy and level systems and unofficially ran the team's Git workflow, which meant reviewing every commit that shipped. Inside my branch and code review workflow, I keep close at hand AI coding tools like Claude Code for drafts, boilerplate and project structure.

I build worlds and write stories as Dungeon Master for a weekly live table, which is really narrative design with an audience that talks back. I also spent four years producing and shoutcasting UD's live esports broadcasts, which means I'm comfortable being the person who keeps a live, public thing running on schedule.

This summer I interned at IndeVets, owning the frontend of a Reddit-style community app for veterinarians. Since then I've shipped The Last Alchemist, a 10-day Game Boy jam game, and designed the enemies for a Scream Jam horror game that was later scrapped. Right now I'm programming a Dead Space-style horror game and building a game I plan to release on Steam and the iOS App Store.
