01 About

Programmer first. Storyteller always.

I'm a Computer Science and Game Studies double major with an English minor who's happiest owning both sides of a game: the systems that run it and the story that justifies them. On "Tails of the Tower," I was one of nine programmers in a 24-student capstone studio, building enemy and level systems while also unofficially running the team's Git workflow — reviewing every commit that shipped. I build with AI coding tools like Claude Code close at hand — for drafts, boilerplate, and project structure, inside a normal branch and code review workflow — but the code that ships is still mine to write and answer for.

Outside the classroom I run live tabletop campaigns most weeks as a Dungeon Master, which is really just narrative design with an audience that talks back. I also spent four years producing and shoutcasting UD's live esports broadcasts, which means I'm comfortable being the person who keeps a live, public thing running on schedule.

Right now I'm splitting time between a Reddit-style community app for veterinarians (my current internship) and two personal games — a souls-like boss encounter in Unreal, and a second project currently in early development. This site is my own build too: designed, coded, and deployed by hand, no framework.
